Raccourcis et rappels
  • 1–9 pose dans le mode actif, Maj+chiffre pose une marque.
  • Appui long sur une case : pose une marque en mode Nombre ou Hypothèse, et un nombre en mode Marque.
  • N M H changent de mode, Suppr efface, flèches pour bouger.
  • ? indice, Ctrl+Z annule, Échap ferme l'indice.
  • X-Wing : un chiffre limité à deux places sur deux lignes, alignées sur les mêmes colonnes.
  • XY-Wing : un pivot {A,B} voit deux pinces {A,C} et {B,C} ; C disparaît des cases qui voient les deux pinces.
  • W-Wing : deux cases {A,B} identiques reliées par un lien fort sur A ; B disparaît des cases qui voient les deux.
  • L'aide utilise tes marques quand une case en a, sinon tous les candidats possibles.
